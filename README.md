
# Диетолог в кармане (MVP)

## Как использовать:
1. Распакуйте архив.
2. Откройте файл `index.html` в браузере (рекомендуется Chrome или Safari).
3. Для публикации на GitHub Pages:
   - Создайте новый репозиторий.
   - Загрузите все файлы из архива.
   - В настройках репозитория включите GitHub Pages (source: root `/`).
   - Получите ссылку на приложение и откройте её на телефоне.

## Основные функции:
- Сканирование продуктов через камеру.
- AI-Анализ продуктов и ингредиентов.
- Рецепты по выбранной кухне.
- Корзина покупок.
- Регистрация с выбором:
  - Языка (RU, UA, EN, FR, HY, DE, ZH и др.)
  - Цветовой темы (7 вариантов)
  - Статуса (кормящая мама)
  - Способа удаления фото (авто / вручную)
- Тестовая интеграция оплаты.

## Рекомендации:
- Лучше запускать в мобильном браузере для теста.
- В папке можно заменить фоновые изображения и логотип.
